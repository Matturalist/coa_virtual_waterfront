# Bar Harbor Waterfront

A browser boat simulator of the Gulf of Maine coast: real bathymetry, charts, tides, geology and habitat, built as a teaching tool for hydrodynamics and boat design.

**Play:** https://matturalist.github.io/coa_virtual_waterfront/

This repository holds the playable build only; it is generated from the project's working repository. See CREDITS.md for third-party models. Some models are CC BY-NC (non-commercial).
